# URBAN CUT — Barbershop Website Concept

URBAN CUT is a one-page website concept for a contemporary barbershop, created as a portfolio project. It pairs a restrained visual identity with clear service information, an editorial gallery, and responsive navigation.

## Project goals

- Present a polished, cohesive barbershop brand concept.
- Demonstrate responsive front-end development using native web technologies.
- Build an accessible, image-led experience without unnecessary dependencies.

## Built with

- Semantic HTML5
- CSS3
- Vanilla JavaScript

## Highlights

- Responsive layouts for mobile, tablet, and desktop screens.
- Mobile navigation with keyboard support.
- Service cards with illustrative prices and durations.
- Local photography with descriptive alternative text and lazy loading below the hero.
- Keyboard-visible focus states and reduced-motion support.

## About this project

This project was developed with an AI-assisted / Vibe Coding workflow. It is an independent portfolio concept and was not commissioned by or created for a real barbershop. Service details and prices are illustrative; the site does not offer real appointments or business contact information.
