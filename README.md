# URBAN CUT — Barbershop Website Concept

URBAN CUT is a concept landing page for a modern men's barbershop. It explores a restrained visual identity, editorial photography, and a clear presentation of grooming services.

**Live preview:** [urban-cut.se4ovichcld.workers.dev](https://urban-cut.se4ovichcld.workers.dev/)

## Project goal

Create a polished, responsive portfolio example that demonstrates front-end development and UI design using the existing lightweight web stack.

## Built with

- Semantic HTML5
- CSS3
- Vanilla JavaScript

No front-end framework, build step, or booking integration is required.

## Highlights

- Dark charcoal and warm beige palette with a minimal editorial layout.
- Responsive hero, service list, approach section, photo gallery, and concept call to action.
- Accessible navigation with a keyboard-operable mobile menu.
- Local photography with descriptive alternative text and lazy loading for gallery images.
- Illustrative USD service prices and durations; no real contact details, appointment form, or booking service.
- Reduced-motion support and visible keyboard focus states.
- JPEG source photographs kept alongside smaller optimized copies in `assets/optimized/`.

## Responsive design

The layout adapts across small phones, larger phones, tablets, laptops, and desktop displays. The gallery adjusts from one column on narrow phones to two columns on tablets and three columns on larger screens.

## Project images

Image files are stored in `assets/`; smaller JPEG derivatives used by the page are in `assets/optimized/`. The original files have been retained. Confirm image ownership and usage rights before publishing or reusing the photographs.
